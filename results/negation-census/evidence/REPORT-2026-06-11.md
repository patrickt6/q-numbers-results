# S1 overnight report, 2026-06-11: what the ML actually found

One-night summary of the first full S1 cycle (build, 668k-constant atlas,
probe grid, D2 open-problem labels, deep tier). Everything below is
reproducible from outputs/RUNS.csv, data/*/manifest.json, and the committed
code (<repo> 0c2216d, 0bd049d).

## 1. The probes found nothing, and that result is solid

Nine t1 runs on the 668,745-row atlas: logistic regression and a small CNN,
inputs c_n mod 2/3/5/7 and the log-magnitude profile over window [64, 320),
labels period parity and omega(D). Every run sits at chance (balanced
accuracy 0.499 to 0.506). The family-average curves (murmuration plots) by
discriminant are flat noise.

In ML terms: under these model classes and feature streams, the mid-range
coefficient windows carry no detectable mutual information about CF period
parity or the prime-factor count of D. This is a clean negative with unusual
strength for the genre, because the labels are exact (no label-noise excuse)
and the dataset is large.

The baseline discipline earned its keep twice. The original family label
scored 94.5% accuracy, which equals the majority baseline exactly (the label
reflected formula presentation, not arithmetic). The unweighted CNN scored
93.99%, also exactly the majority baseline. Both would have read as
"the model learned something" without the baseline column next to them.

## 2. The D2 story: a perfect classifier that was right for the wrong reason

(Sections rewritten 2026-06-11 daytime after the t2 probe ran; the overnight
draft of this section claimed a 36x palindrome enrichment in the finite
class. That claim is RETRACTED below. The earlier text is in git history.)

The D2 pass decided negation-sum finiteness ([x]_q + [-x]_q finite or not,
the open Ovsienko Example 6.4 question) for 668,745 constants. Version 1
reported 2,061 finite_observed. The t2 probe trained on six CF scalar
features then scored a PERFECT 1.000 balanced accuracy on held-out
discriminant bands, and a depth-1 decision tree reproduced it with one split:
longest_zero_run > 503 implies finite.

That split is not mathematics, it is a window artifact, and the model is the
thing that found it. A zero run longer than 503 inside a 512-coefficient
window means the stored [x]_q is indistinguishable from a polynomial there,
which happens exactly for constants within ~10^-3 of 1: their CF has a huge
early partial quotient (the depth-2 tree's max_pq > 504 branch is literally
"the CF term exceeds the window"), so all structure, including the negation
sum's infinite tail, lives beyond q^512. The v1 labeler called those rows
finite. The 36x palindrome enrichment was this artifact's shadow (near-1
constants carry symmetric period words with one huge entry), and it is
retracted.

Correction applied: every v1 finite row with max_pq > 252 (2,059 of 2,061)
was recomputed at window 4096 with the same guard logic. Result, written as
labels_v2.parquet:

    finite_observed: 2 (sqrt(2) and sqrt(3), and nothing else)
    infinite_observed: 668,439
    undecided: 304

So the honest empirical statement, and it is a strong one for the open
problem: among all 668,745 canonical quadratic irrationals in (1, 2) with
D <= 20,000 and height <= 10, the negation sum is observed-finite for
exactly two constants. Finiteness under this convention is radically rarer
than the (false) trace-zero criterion ever suggested. Caveat: labels attach
to canonical representatives in (1, 2); finiteness is convention-sensitive
under integer translation, so literature statements about e.g. 4 + sqrt(7)
are about a different representative and are not contradicted.

In ML terms this is the pipeline's adversarial loop working end to end: a
too-good metric triggered attribution, attribution localized the artifact to
one interpretable feature, exact recomputation at 8x depth settled every
suspect, and the run record preserves the whole chain.

## 2b. t4: the first genuinely positive probe

Radius regression on the new deep tier (18,210 constants, 4,096 exact
coefficients each, R from the tail slope, 581 unreliable rows dropped):
random forest R^2 = 0.54 (ridge 0.34), MAE 0.057, on held-out discriminant
bands. Period length dominates the importances (0.38), then period_sum and
max_pq (~0.19 each); the palindrome flag is irrelevant (0.004). CF shape
genuinely predicts about half the variance in R(x) out of distribution.
Binned residuals are flat at +-0.01 with a mild over-prediction drift at the
largest discriminants; that drift is a candidate for the exact-recompute
gate, not a claim.

## 3. Engineering results that change future cost

- qreals' truncated series path measured 0.13 constants/sec/core at depth
  512 (one series inversion per CF term). The replacement kernel
  (datagen/qserieskernel.py, numerator/denominator fold, one division)
  measured 48/sec/core, a 370x speedup, with exact agreement pinned by tests
  at depths 48 and 512. Worth upstreaming to the qreals package.
- Calibration against the five known verdicts (sqrt2 finite, sqrt19/43/46/53
  infinite) caught two bugs that would have silently mislabeled the entire
  D2 dataset (trailing-zero trimming, precision-edge garbage at the window
  top). "CI for the training data" is not a slogan; both bugs produced
  plausible-looking output.
- Full force-kill resume drill passed; the overnight chain (D2 full pass +
  18,210-constant deep tier at 4096 coefficients) completed unattended with
  0 errors.

## 4. What this sets up

1. The "only sqrt(2) and sqrt(3)" statement wants a collaborator-facing
   writeup: it is checkable, quantified, convention-explicit evidence that
   canonical-window finiteness is essentially unique, and the 304 undecided
   rows are an explicit finite to-do list (deeper windows or exact methods).
2. t4's R^2 = 0.54 invites the next murmuration pass: which period-word
   features close the remaining variance, and whether the high-discriminant
   residual drift survives exact recomputation.
3. B1 (grokking the proved sqrt2 mod 2 automaton) is the next training
   experiment queued; it is the one with a publishable story independent of
   outcome.
4. Anything claimed from here passes the exact-recompute gate first; this
   report now contains one retraction precisely because that gate exists.
