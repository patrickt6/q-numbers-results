## Statement

The divisor hypothesis is a theorem for n <= 6, by Kogiso-Miyamoto-Ren-Wakui-Yanagawa and Byakuno-Ren-Yanagawa. For n >= 7 it is open.

```math
\begin{aligned}
&x=\tfrac ad,\ \ [x]_q=\tfrac{N}{S}\ \text{reduced}:\qquad \Phi_e\mid S\ \Longrightarrow\ e\mid d\\
&\text{theorem for }2\le e\le6;\ \ \text{open for }e\ge7
\end{aligned}
```

*Open:* Stated precisely, not settled.
